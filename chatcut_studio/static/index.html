ChatCut Studio

歌曲工坊：原曲 → 分离人声 → 降调 → 素材文件夹；也可以连接模型，交给 Agent 在 ChatCut 里剪。

新建一首歌

选原曲（mp4 视频或 mp3 / wav 等音频），会在 下建一个文件夹，所有素材按步骤放在里面。

剪辑 Agent 用什么驱动

两种方式二选一，随时可以切换。

模型服务商

填入 API Key 后点「获取模型列表」选择模型。Key 只保存在本机 chatcut_studio/data/settings.json，也可以用环境变量提供。

在 ChatCut Desktop 里用 DeepSeek

ChatCut Desktop 的 AI 面板里，输入框旁边的 Agent 按钮列出的是本机装好的 Agent：「ChatGPT」就是本机的 Codex，「Claude」是 Claude Code。 点下面的「接入」，它们就改为通过本程序调用上面配置的 DeepSeek；在 Studio 里换模型、换 Key 立即生效。

用法：① 在上面「模型服务商」填好 DeepSeek 的 base_url、Key、模型 → ② 点「测试 DeepSeek」→ ③ 点「接入 Codex」→ ④ 重启 ChatCut Desktop，AI 面板 Agent 按钮选「ChatGPT」，新开一个对话。
注意：接入期间本机所有 Codex 会话都会用 DeepSeek，而且 Studio 要保持运行；点「断开」恢复原来的设置。 「Claude Code 方式」里的「一键安装插件」是给已装好的 Claude Code 装 ChatCut 插件，走 Codex 不需要它。
