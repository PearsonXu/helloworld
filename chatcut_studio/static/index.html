模型服务商

填入 API Key 后点「获取模型列表」选择模型。Key 只保存在本机 chatcut_studio/data/settings.json，也可以用环境变量提供。

ChatCut 连接（API 模型方式）

本程序直接连接 ChatCut 的 MCP 服务。连接后会列出 ChatCut 提供的全部工具和本程序对每个工具的权限策略。

浏览器登录的回调地址是 。ChatCut 是否允许第三方程序这样登录还需要实测；不行的话可以改用 Claude Code 插件方式。没有 ChatCut 账号时，可以运行 python3 -m chatcut_studio.fake_chatcut，把地址改成 http://127.0.0.1:8766/mcp、认证选「不认证」来测试整条链路。
