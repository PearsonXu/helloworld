# 歌曲 MV 背景图（竖版 9:16 · 1080×1920）

## 重新生成 / 调整

```bash
python3 paint.py            # 重画全部 5 张（需要 numpy、Pillow）
python3 paint.py 03         # 只重画名字里带 "03" 的那张
```

每张图由 `paint.py` 里对应的 `scene_*` 函数绘制，颜色都写成十六进制，改色值即可调色；随机种子固定，结果可复现。
